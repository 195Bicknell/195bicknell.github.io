# Images

Drop photos here using these exact file names:

- `badge.png` — corps badge for the header
- `slide1.jpg`, `slide2.jpg`, `slide3.jpg`, `slide4.jpg` — hero slideshow (landscape, ~1920×1080)
- `gallery1.jpg` … `gallery6.jpg` — scrolling gallery strip (~900×600)

Missing files fall back to a navy gradient. Get permission from parents/guardians before
posting photos where cadets can be identified, and follow your corps' social media and photo policy.
